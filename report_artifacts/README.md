## Model printouts for the report

These files contain the exact `repr(model)` output used in the report appendix.

Regenerate (downloads the pretrained model if needed):

`./venv/bin/python scripts/dump_resnet20_prints.py --pretrained`

Outputs:

- `report_artifacts/resnet20_before.txt`
- `report_artifacts/resnet20_after_convert_to_kan.txt`
